# srcrecon · 授权资产侦查流水线

一个**只用标准库**的被动侦查工具：输入域名，输出可直接贴进 SRC 提交框的资产报告。

不发送任何攻击载荷，只做公开信息收集与轻量 GET 探测。

```bash
python srcrecon.py example.com --out report.md --json out.json
```

## 它做什么

| 阶段 | 内容 | 数据来源 |
| --- | --- | --- |
| 子域枚举 | 证书透明日志 + 常见子域字典 | crt.sh / DNS |
| 存活探测 | HTTPS→HTTP 回退，状态码、标题、Server | 直接请求 |
| 指纹 | Server / X-Powered-By / 标题 | 响应头 |
| 路径探测 | robots、sitemap、security.txt、admin、actuator、.git、.env 等 | 只 GET，看状态码 |
| 接口提取 | 从首页 JS 里抽 `/api/*`、`/v1/*`、`/graphql` 等 | 正则 |

输出两份：`report.md`（人看，可提交）+ `out.json`（程序用，可入库对比历史）。

## 实测输出（example.com）

```
子域 11 个，存活 2 个
example.com      https://example.com/      200  Example Domain  cloudflare
www.example.com  https://www.example.com/  200  Example Domain  cloudflare
```

## 合规边界（必须遵守）

- **只对你有授权的目标运行**：自己的资产、SRC 平台明确列出的范围、或书面授权
- 工具本身不含 payload，但**拿报告去测试前，仍要确认目标在授权范围内**
- 不要对同一个目标高并发扫描（本工具默认 8 线程、6 秒超时，已经算克制）
- `/.git/config`、`/.env` 这类路径只记录**状态码**，不下载内容、不利用
